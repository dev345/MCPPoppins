# MCPoppins website sitemap

## Primary navigation

- `/` — Home: proposition, cross-channel agent demo, trust promise, featured kits, competition story.
- `/marketplace` — Filterable connector and channel catalogue without sign-in.
- `/packages/[slug]` — Reusable package template.
  - `/packages/jira` — Jira sample listing.
  - `/packages/confluence` — Confluence sample listing.
  - Slack and Telegram sample/roadmap listings share the same template.
- `/workflows` — Outcome-led workflows, example prompts and 90-second judge script.
- `/docs` — Installation and usage-guide layout for local, hosted and enterprise modes.
- `/pricing` — Community, Pro, Team and Enterprise hypotheses with no invented prices.
- `/trust` — Identity, permissions, action risk, supply-chain evidence and release gate.

## Deferred product routes

- `/playground` — Live seeded tenant and trace explorer.
- `/developers` — SDK, schema, testing and publishing guidance.
- `/account` — Connections, scopes, approvals, audit, usage and billing.
- `/status` — Service status and disclosures.

## Primary user paths

1. Judge: Home demo → Workflows → Jira package → Trust.
2. Developer: Marketplace → Package detail → Local install guide.
3. Team lead: Home → Team workflow → Pricing placeholder → Trust.
4. Platform lead: Trust → Package permissions → Enterprise mode.
